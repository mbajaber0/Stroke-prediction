# Stroke Prediction AI Solution

## Project Overview
This project was developed as part of BTEC Level 3 Unit 21 - Introduction to Artificial Intelligence.
The aim is to predict the likelihood of stroke using patient health data and Logistic Regression.

## Dataset
Healthcare Stroke Prediction Dataset (Kaggle)

## Tools & Libraries
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- Google Colab

## Model Used
- Logistic Regression (Initial and Refined with class_weight='balanced')

## How to Run
1. Open the notebook in Google Colab or Jupyter
2. Run all cells
